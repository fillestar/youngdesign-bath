1단계: 고객과 통화 종료

갤럭시 기본 전화 앱이 통화를 자동으로 고음질 녹음합니다 (`/Recordings/Call/*.m4a`).

💡 갤럭시 사전 세팅: 전화 앱 → 설정 → [통화 녹음] → [통화 자동 녹음: 모든 전화] 켜기

2단계: MacroDroid 자동화 앱이 '통화 종료' 감지

무료 매크로 앱 MacroDroid가 통화 종료 트리거를 낚아챕니다. 단골 자재상이나 가족 번호는 1차 제외 필터로 스킵합니다.

💡 구글 플레이스토어: 무료 앱 MacroDroid (기기 자동화) 설치 후 백그라운드 배터리 최적화 예외 설정

3단계: 구글 무료 Gemini Flash API 분석

통화 내용에서 아파트명, 평형, 리모델링 항목, 방문 약속을 추출하고 어림금액 분쟁 방지 가드를 적용합니다.

🛡️ 자재상/스팸 통화 시: AI가 "거래처 통화"로 판별하여 매크로 즉시 종료 (문자 발송 원천 차단)

자주 묻는 질문 (FAQ)
비용·보안·오작동
Q. 시스템 운영에 매달 비용이 들어가나요?
전혀 들지 않습니다 (0원). 구글 Gemini 2.5 Flash API는 분당 15건, 하루 1,500건까지 완전 무료로 제공됩니다. 하루 상담 통화 10~30건 정도는 평생 100% 무료 범위 내에서 여유롭게 작동합니다.
Q. 통화 내용이 유출되거나 학습에 쓰이지 않나요?
안전합니다. 구글 제미나이 유료/개발자 API 엔드포인트는 구글 서비스 약관상 고객의 대화 데이터를 AI 모델 재학습에 사용하지 않는 기업용 보안 규격을 준수합니다. 또한 개인정보(주민번호, 계좌 비밀번호 등)는 통화에서 수집하지 않습니다.
Q. 현장에서 인터넷이나 데이터가 안 터지면 어떡하나요?
시뮬레이터에 내장된 것과 동일하게, 네트워크 연결이 불안정할 때는 스마트폰 자체 오프라인 템플릿(정규식 추출기)이 가동되어 아파트명과 시간만 안전하게 채운 표준 양식 문자를 생성합니다.
