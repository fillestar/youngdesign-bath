📞 통화 후 안내문자 3초 생성기

고객 통화 후 상황 버튼만 톡 누르면 정중한 전문 안내문자가 자동으로 완성됩니다. 타자 칠 필요 없이 터치 한 번으로 문자 앱이나 카카오톡으로 바로 전송하세요!

1 통화 상황을 골라주세요 (터치 시 즉시 문자 반영)
📅 무료 방문실측 예약
방문 약속 확인 + 현장 점검 후 투명한 정식 견적 안내
🏠 거주 중 안심시공
먼지·소음 차단 보양 안내 + 실측 방문 일정 조율
📸 타일보수 사진요청
들뜸/파손 부위 근접 사진 + 전체 사진 문자 요청
📇 모바일 명함 인사
기본 상담 감사 인사 + 공식 블로그/포트폴리오 안내
2 공사 항목을 선택하세요
3 현장명 & 방문일시 (선택사항 — 비워두셔도 자연스럽게 완성!)

⚠️ 브라우저 보안 알림
현재 로컬 파일(내 컴퓨터 직접 열기 또는 카카오톡 인앱 창)에서는 보안 정책 때문에 마이크 작동이 차단될 수 있습니다. 아래 정식 웹페이지를 여시면 마이크 녹음이 100% 정상 작동합니다!

부모님 갤럭시 스마트폰 (MacroDroid 무료앱)

  1. 구글 플레이스토어에서 MacroDroid 앱을 설치합니다.
  2. [매크로 추가] 누른 후:
    • 트리거: [통화] → [통화 종료됨] 선택 (수신/발신 모두)
    • 작업: [애플리케이션] → [웹사이트 열기] 선택 후 아래 주소 입력:
      https://fillestar.github.io/youngdesign-bath/ai-call.html
  3. 저장하면 이제 통화가 끝날 때마다 자동으로 이 문자 생성기가 화면에 짠 나타납니다!

동생 아이폰 (사파리 홈 화면 바로가기)

  1. 아이폰 Safari 브라우저로 이 페이지를 엽니다.
  2. 하단 중앙의 공유 버튼(네모에 위 화살표)을 누릅니다.
  3. [홈 화면에 추가]를 누르고 이름을 '문자 생성기'로 저장합니다.
  4. 통화 종료 후 홈 화면의 아이콘을 톡 누르면 1초 만에 바로 열립니다!
